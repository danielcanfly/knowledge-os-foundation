# 08｜Workspace and Memory

## Workspace question

```text
What is happening in the current task?
```

## Workspace contains

```text
task.json
plan.md
findings/
artifacts/
scratch/
checkpoints/
```

## Memory question

```text
What should be retained beyond this task?
```

## Memory classes

```text
episodic memory
project memory
semantic user memory
```

## Hard distinction

```text
Workspace = temporary task state
Memory = reusable experience or preference
Knowledge = durable verified source-backed truth
```

Agent observations cannot directly become production knowledge.
