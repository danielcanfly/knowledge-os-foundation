# W5 E15 | Versioned original-523 evaluator admission mechanics (isolated, non-production)

**Scope:** metadata-only, offline, independent evaluator-side intake; no access to sealed case bodies; no Provider/IdP/paid API calls; no official benchmark execution. All tests are **synthetic local-only** and must never be reported as the original 523 score or AR09 Phase B score.

## Contract

Module: `knowledge_engine.m27_w5_e15_original523_evaluator_admission_v1_experimental`. It exposes typed immutable `SourcePin`, `OpaqueCase`, `FrozenImage`, `SealedManifest`, `ScoredCase`, `SignedClaim`, `RunPacket`, `TrustRoot`, `IndependentContext` and `inspect()`. It neither imports hidden cases nor accepts question/final-answer text or answer keys; scorer-supplied SHA256, source IDs, span offsets, counted bytes, source revisions, and rubric metadata are opaque *claims*, not content proof.

- Two distinct cohorts: `ORIGINAL_523` must freeze exactly **523** opaque, unexposed case IDs before scoring; `AR09_PHASE_B_200` freezes **200** and cannot qualify an original-523 product gate. `HISTORICAL_REPLAY_FIXTURE` is categorically excluded. Duplicate IDs, duplicate lexical hashes, inadequate independently attested intent diversity (<140), insufficient source diversity (<100 revision-pinned sources / 20 documents / 5 families / 5 origins), and exposed/replayed labels are denied. Case IDs/intent fingerprints are *not* a substitute for independently screened real questions. At least 100 sources must actually be referenced; externally pinned origin-to-family/document mappings and two independently authorized reviewers for every case are required. Corpus diversity thresholds are conservative local prerequisites, not newly certified official benchmark policy.
- Seal and rights must be independently resolved against an evaluator-side registry with source native SHA256, span-index SHA256, version/revision, ACL, consent, license and expiry; the candidate-supplied metadata is not independently authoritative.
- Git commit/tree, immutable candidate image, build, runner and instrumentation digests are different fields. A mutable tag, fixture hash, caller's build claim or old Stage30P digest is not an independently built/current executed image.
- Eight distinct independently rooted Ed25519 signer roles: **custodian, rights_issuer, source_verifier, builder, runner, grader, client, observer**. Signed role/payload/scope/expiry is checked. Keys/issuer roots must be obtained and nominated independently of the implementer; root provenance cannot be proven by this code alone. Fixture Ed25519 and HMAC never grant real authority, even when signatures verify cryptographically.
- Scoring binds a frozen roster and independent result set, grader/rubric/version, final-answer SHA and nonzero byte count, exact native source revision/span and hash, independent client first substantive cited byte before terminal, and all failures, rejections, abstentions, missing receipts and timeouts to the **original denominator**. Missing terminal durations produce **unknown p95**, never drop failures and silently compute p95 over surviving successes. The diagnostic `cited_qualified` includes only answerable graded (>=85), cited, properly bound final answers; cited percentage uses **all frozen assigned cases**, with a >=95% threshold only as a diagnostic; p95 diagnostic threshold <=15000 ms is not an official product measurement.
- `inspect` always sets `may_execute_official_evaluation=False` and `official_cited_gate_pass=False`; only the separately authorized independent evaluator / Master release acceptance can run and certify actual product gates. A completely externally attested and successful packet can reach `ORIGINAL523_METADATA_ACCEPTED_FOR_INDEPENDENT_REVIEW`, **never** automatic release/production or an assertion that actual original 523 Q&A was run. A fixture remains `ORIGINAL523_EVIDENCE_NOT_ADMITTED`. Phase B without independently validated real evidence remains `AR09_PHASE_B_BLOCKED`, and missing source authority remains `REAL_SOURCE_RIGHTS_NOT_VERIFIED`.

## Recorded external evidence debt

G09 established 523 historical stored rows as 341 `live_answer_stream` plus 182 `contract_replay` with only **20 NFKC-normalized lexical questions**. Those rows cannot serve as 523 independently unseen scored questions. No lawful independently nominated custodian, sealed original native source spans, external source/consent/license grant, evaluator-only separated hidden corpus, independently verified immutable candidate execution, eight independent signer roots, authentic grader/client receipts, actual reconciled Provider spend or real product p95 is established by this component.

A genuine original-523/Phase B qualification therefore requires independent legal and source custody, genuine case/seal hash from an evaluator not the candidate, signed role/rights ledger, independent build+runner+instrumentation provenance, quality-reviewed complete final answers with actual citation spans and real client-received substantive UTF-8, a fixed complete latency denominator, authentic Provider usage+prices+invoices, separate 200-case Phase B evaluator admission, and explicit release authorization. None is fabricated here.
